# Journey: Creating a Dynamic Tour

> Working document. Filled in collaboratively to describe what a "good" Ondoway tour looks like end-to-end, so we can reverse-engineer rules and validation criteria for the tour-builder.

---

## Persona
First time visitor to Paris who is walking to a museum for a scheduled visit and wants a walking tour on the way.

## Goal
They want to turn a walk into a guided experience so they can increase the value of their time in Paris.

## Trigger
Opening the app.

## Preconditions (true at journey start)
- User has an existing account
- User is on a reliable (home/hotel) wifi connection
- Location Services available

## Success State
User has a custom tour generated within 5 minutes of opening the app. They feel like this tour is enhancing the value of the time they already had planned in the city with very little effort.

## Failure Modes
- Tour is uninteresting
- Agenda is too short and doesn't maximize the user's time
- Agenda is too long or ponderous and makes the user feel like they are wasting their time
