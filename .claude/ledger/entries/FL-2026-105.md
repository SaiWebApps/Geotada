## Incident

Unlike Dart (where the compiler discovers files by import), Xcode compiles only
what `project.pbxproj` lists. Writing a new `.swift` file under
`mobile/ios/Runner/` and rebuilding produces a binary that simply omits it — no
error, no warning, the new native code just never runs. The failure mode is
silent and reads like "my change had no effect", which invites wrong theories
about caching or the simulator. Registration means four coordinated pbxproj
entries (PBXFileReference, PBXBuildFile, the group listing, and the Sources build
phase); a grep for the filename in the pbxproj is the fast tell for whether the
build can see the file at all.
