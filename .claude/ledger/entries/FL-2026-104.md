## Incident

`make flutter-test` was launched with `run_in_background`. Flutter buffers stdout
completely, so the output file stayed at 0 bytes for over 3 minutes while the run
was actually progressing. Claude polled it with `sleep 5` loops — more than 20
polling attempts, every one showing empty output — wasting the user's time on a
run that was never hung. CLAUDE.md Flutter-Specific and the prevent-laziness hook
now mechanically block this, but the rule stands on its own: Flutter commands go
in the foreground, and a long wait gets a one-line status, not silence.
