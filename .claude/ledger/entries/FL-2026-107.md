## Incident

During the Travlr/Geotada to Ondoway rename, four agents swept the codebase — and
every one of them missed `.env.local` and `.env.cloud`, because those files are
gitignored and `grep -rn` / `rg` honor ignore rules by default. The stale
references sat in live config until a later session (2026-04-30) swept them along
with the Makefile and spec files. The blind spot is structural: the very files
most likely to hold environment-specific names (hosts, database names, project
slugs) are exactly the files default search tooling will not show you. A sweep is
not done until the old name returns zero hits with ignore rules disabled.
