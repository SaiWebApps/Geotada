## Incident

The Paris image did not render on the iOS simulator. A prior session had already
left a memory entry saying "try `make flutter-clean && make flutter-ios`". Instead
of following it, this session spawned a Planner that theorized a progressive-JPEG /
Impeller incompatibility, spawned a Developer to convert the image, and declared
success when tests passed. Tests use a separate asset bundle, so they proved
nothing about the simulator build. The user ran `make flutter-ios`, saw no image,
and said "You have failed." The actual fix was `make flutter-clean` — Flutter's
incremental build does not reliably detect binary asset changes. 30+ minutes spent
on a 2-minute fix, and the image conversion was unnecessary.
