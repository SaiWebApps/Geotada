## Incident

Three stacked failures from the same discipline gap. (a) Only `make db-test-up`
(7688) was started, so `make test-local` (which targets 7687) failed — 30 minutes
lost to a "sandbox blocks network" theory. (b) `.env.local` and `.env.test` lacked
`NEO4J_DATABASE`, so the shell fallback supplied the Aura database name `8a37bbaf`
and local tests died with `Graph not found: 8a37bbaf`. (c) Skipping integration
tests were blamed on infrastructure when the causes were wrong port, missing env
var, and `connection.py` overriding test env vars — all visible in the error text.
Port map: dev 7687, test 7688, workbench 7689 (workbench only for
`make test-workbench` / `make api-test`; the pytest suite full-wipes 7688 per
module, so nothing else may point there).
