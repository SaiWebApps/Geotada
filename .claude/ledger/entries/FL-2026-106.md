## Incident

Three related failures. (a) The corporate proxy blocks pip's direct access to
pypi.org — multiple `pip install` attempts died with `ProxyError: 403 Forbidden`.
(b) Instead of diagnosing, Claude flailed through `--trusted-host`,
`--no-build-isolation`, and other flags — three failed retries before stopping to
think. (c) Raw `uv run pytest` / `uv run python` bypassed Makefile targets that
encode env setup (`make test-local` copies `.env.local` to `.env.test` first),
producing inconsistent results. The project pins public PyPI in `pyproject.toml`
so `uv.lock` is reproducible anywhere; `make sync-apple` re-resolves via
`pypi.apple.com` but restores the public lock afterward — which is why a committed
lock containing any `pypi.apple.com` URL is always a bug.
